# Challenges de Estructuras de Datos II

Cada challenge está en su propia rama y todas se mezclaron sobre `main`.

| Rama | Challenge | Estructura |
| ---- | --------- | ---------- |
| `03-listas` | 03 | Lista simple y lista doble |
| `04-pila-libros` | 04 | Pila |
| `05-cola-cajero` | 05 | Cola |
| `08-arbol-binario` | 08 | Árbol binario |
| `09-arbol-nario` | 09 | Árbol N-ario |
| `10-grafo-amigos` | 10 | Grafo |
| `11-trie-heap` | 11 | Trie y Heap |

Para correr cualquiera:

```
cd 04-pila-libros
npm install
npm run dev
```
